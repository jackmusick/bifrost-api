# Bifrost

## Platform

web

## Users and purpose

Bifrost is an automation platform for MSP operators and the people using their apps and forms. Operators manage organizations, workflows, agents, code, integrations, dependencies, forms and execution outcomes. Public and embedded entry points support narrower customer tasks.

## Confirmed modernization brief

The user authorized a complete frontend review and modernization using the existing Bifrost Design System, preserving familiar behavior and avoiding confusing changes. Every page is in scope, with particular attention to execution, forms, lists, dependencies and the code editor. Mobile usability, coherent motion and visual craft are required.

## Compatibility

Custom branding, product terminology, logos, permissions, V1 included component APIs, app mounting and existing runtime transports are product contracts. The platform and built apps should share a consistent theme without creating independent competing stores.

## Evidence

Product structure comes from the checked-out application, routes and repository instructions. Design authority is the canonical `gobifrost/design-system` at `11da72e`. Page-specific design decisions remain to be recorded against observed behavior; no unobserved page is presumed complete.
