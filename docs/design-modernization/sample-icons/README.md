# Sample resource artwork

Generated illustrative artwork for the design review debug stack. These are
optional uploaded assets, not replacements for the product's Lucide fallbacks
or tenant branding.

- `customer-workspace.png`: customer-facing app / service portal.
- `customer-intake.png`: intake form / request service.
- `knowledge-assistant.png`: knowledge agent / lookup service.

Use the normal logo upload controls to attach them to a resource. The backend
creates bounded thumbnails; the original images are retained here for reuse.
The shared `ResourceIcon` uses 48px for card identity, 32px in tables, and 24px
in compact resource pickers. Logos use contain fitting so uploaded brand marks
are not cropped. Missing or failed images retain the resource-kind fallback.
