# Access and shell acceptance inventory

Scope: `client/src/App.tsx` public access routes, device/OAuth/MCP callbacks, embedded form routes, and shared shell actions that sit outside individual feature pages. This inventory records source paths, user actions, existing test evidence, and acceptance gaps. Component tests and route smoke tests are listed as evidence, but a heading-only or mocked component test is not treated as full acceptance for a live user journey.
